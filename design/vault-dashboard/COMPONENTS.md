# Components & States
| Component | States / variants |
|---|---|
| SideNav / NavItem | default, hover, active (inset accent bar), with badge count |
| PhoneTabBar | 5 tabs, active |
| PageHeader | title, subtitle (needs-you + minutes), actions |
| RangeSegment / Segmented | Today/Week/Month; Dark/Light; Desktop/Phone; selected |
| Button | default, primary, danger (outline red), hover, focus, disabled |
| KpiCard | value (rolling), delta up/down, sparkline or progress, loading skeleton |
| BriefingCard | narrative, top-3 priorities, GoalRing (0–100%) |
| ApprovalRow (Needs you) | type, amount, owner-minutes; Approve / Review / Edit / Reject; approved → collapse |
| ScheduleRow | time pill, job, crew, duration |
| DensityBars | per-day load; low day dimmed |
| TeamStatusRow | avatar orb, one-liner, pill: working / waiting / idle / blocked / paused |
| PipelineKanban / Column / LeadCard | New, Contacted, Quoted, Booked, Won; card: name, scope, value, source; drag (build) |
| WeekCalendar / JobBlock | crew color variants (accent, ok, violet-grey), span by hours; empty slot |
| CapacityCard / OpenSlotRow | % booked, Fill action |
| CrewCard | members stack, status (on job / driving / available / off), quality bar |
| InvoiceTable / StatusPill | paid (ok), sent (neutral), due (warn), overdue (bad) |
| PayoutBatch | rows, total, labor %, Approve batch |
| AreaChart | 12-mo revenue |
| ExperimentRow | winning / running / learning / stopped |
| AgentOrb | idle, working (pulse), waiting (slow breathe), blocked (muted tint), paused (static, 50%) |
| KillSwitch | armed, confirm modal, all paused |
| RoastEntry / VerdictRow | Go / Test first / No |
| AutomationToggle | on, off, error |
| GuardrailRow | value, editing |
